# ESP32-C3-MINI-1 KiCad library assets

The symbol, footprint and STEP model in this project come from Espressif Library 3.2.1, published by Espressif Systems and credited in its package metadata to Pedro Minatel. These assets are available under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). [Upstream KiCad library](https://github.com/espressif/kicad-libraries)

This project stores the symbol and footprint under its local `Espressif` library nickname and points the footprint at the local STEP model. The symbol comes from the existing schematic cache. The edits update library links and the 3D model path.
